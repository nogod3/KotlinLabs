## Что делает программа

Программа проверяет, может ли пользователь выполнить действие над ресурсом. Она получает логин, пароль, действие, путь до ресурса и объем через аргументы командной строки. В обычном режиме программа ничего не печатает, а возвращает нужный код.

Пароли внутри программы не хранятся открытым текстом. Для проверки используется SHA-256 с индивидуальной солью. Данные пользователей, ресурсов и прав находятся прямо в коде, база данных не используется.

## Тестовые пользователи

| Логин | Пароль | Права |
|---|---|---|
| `alice` | `qwerty` | чтение и запись `A`, выполнение `TOOLS`, чтение `PRIVATE` |
| `bob` | `secret123` | чтение `A.B` и `PUBLIC` |

Права родительского ресурса наследуются дочерними ресурсами. Например, права `alice` на `A` применяются и к `A.B.C`.

## Сборка

Нужны JDK, Kotlin command-line compiler и Git Bash либо WSL. Переменная `KOTLIN_HOME` должна указывать на каталог Kotlin compiler или команда `kotlinc` должна находиться в `PATH`.

```bash
./build.sh
```

Система сборки Gradle или Maven не используется. Скрипт напрямую вызывает `kotlinc` и создает исполняемый `app.jar`.

Для сборки из обычной командной строки Windows можно использовать:

```bat
build.bat
```

## Запуск

```bash
./run.sh --login alice --password qwerty --action read --resource A.B.C --volume 10
```

Или напрямую:

```bash
java -jar app.jar --login alice --password qwerty --action read --resource A.B.C --volume 10
```

Справка:

```bash
./run.sh --help
```

## Тесты

```bash
./test.sh
```

Скрипт проверяет успешный запуск и все коды ошибок. В конце должен появиться результат `10/10`.

В Windows также можно выполнить `test.bat`.

## Коды возврата

| Код | Значение |
|---:|---|
| 0 | успешное выполнение |
| 1 | справка или неверный формат запуска |
| 2 | неверный пароль |
| 3 | неверный логин |
| 4 | неизвестное действие |
| 5 | нет доступа |
| 6 | ресурс не существует |
| 7 | неверный формат ресурса или объема |
| 8 | превышен максимальный объем |
